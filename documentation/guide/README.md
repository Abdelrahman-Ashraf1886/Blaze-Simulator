# Blaze UAV user guide

Blaze UAV lets you design a hobby multicopter and fly the model on your PC. Start with an assembly and enter the values you have for your design. The app lists the missing inputs that block a run. [Workshop panels](../../src/features/workshop/WorkshopPage.tsx#L624) · [Flight setup](../../src/features/flight/FlightSetup.tsx#L98)

The screenshots show a test quad and a simulated gamepad. Use your own build data and flight conditions. [Test build](../../tests/e2e/helpers.ts#L63) · [Simulated input](../../tests/e2e/helpers.ts#L113)
