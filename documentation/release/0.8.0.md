# Blaze UAV 0.8.0

The app and engine ship together as 0.8.0 for Windows x64. This private release includes an unsigned installer and portable executable with SHA-256 checksums. See the [release guide](README.md) for checksum verification, what SmartScreen may show, and the upgrade steps.

Recordings made with engine 0.1.0 will show **cannot verify** when verified against 0.8.0. Verification requires the engine version and protocol recorded in the file (`electron/main/telemetry/verify.ts:103–107`).

**Help → Check this computer** compares the final state hashes of three stored runs against the 0.8.0 release engine. The references were captured on an Intel Core i7-9750H at 2.60 GHz.
